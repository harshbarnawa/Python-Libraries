# Python Libraries

This repository contains my learning and practice with various **Python libraries** commonly used in Data Science, Machine Learning, and AI.

The main focus is on understanding the libraries through practical examples, exercises, and small experiments rather than just learning the syntax.

## 📚 Libraries will be Covered

* **NumPy** — Numerical computing and arrays
* **Pandas** — Data manipulation and analysis
* **Matplotlib** — Data visualization
* **Seaborn** — Statistical data visualization
* **Scikit-learn** — Machine Learning
* **PyTorch** — Deep Learning
* **TensorFlow / Keras** — Deep Learning
* **OpenCV** — Computer Vision
* **Hugging Face** — NLP and LLMs

More libraries will be added as I explore them.
