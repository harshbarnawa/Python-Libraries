1. NUMPY ARRAY BASICS — MUST
----------------------------

What is NumPy?
--------------
NumPy is Python's core numerical computing library.

Its main object is the ndarray (N-dimensional array).

Why NumPy matters for AI/ML:
- Numerical data is represented as arrays.
- ML datasets are usually matrices.
- Neural networks work with tensors, which follow similar ideas.
- Vectorized NumPy operations are much more efficient than manual Python loops.

Basic array:

    import numpy as np

    x = np.array([1, 2, 3, 4, 5])

2D array:

    X = np.array([
        [1, 2, 3],
        [4, 5, 6]
    ])

[ ] Understand 1D arrays
[ ] Understand 2D arrays
[ ] Understand 3D+ arrays conceptually
[ ] Understand ndarray

11. AXIS — VERY IMPORTANT
--------------------------

Do not skip this.

Example:

    X = np.array([
        [1, 2, 3],
        [4, 5, 6]
    ])

axis=0:

    X.sum(axis=0)

Result:

    [5, 7, 9]

This operates down the rows and produces one result per column.

axis=1:

    X.sum(axis=1)

Result:

    [6, 15]

This operates across the columns and produces one result per row.

Important mental model:

    axis=0
    -> result per column

    axis=1
    -> result per row

ML example:

    X.mean(axis=0)

means mean of every feature/column.

    X.mean(axis=1)

means mean of every sample/row.

[ ] Understand axis=0
[ ] Understand axis=1
[ ] Understand shape of axis results
[ ] Can explain axis without memorizing blindly


12. BROADCASTING — VERY IMPORTANT
---------------------------------

Broadcasting allows NumPy to perform operations on arrays with compatible shapes.

Example:

    X = np.array([
        [1, 2, 3],
        [4, 5, 6]
    ])

    y = np.array([10, 20, 30])

    X + y

Result:

    [[11, 22, 33],
     [14, 25, 36]]

NumPy effectively applies y to every row.

Also:

    X + 10

adds 10 to every element.

[ ] Understand scalar broadcasting
[ ] Understand row-wise broadcasting
[ ] Understand compatible shapes
[ ] Understand why incompatible shapes produce errors

Broadcasting is extremely important later in PyTorch.


13. BOOLEAN MASKING — MUST
--------------------------

Boolean masking is used to filter array data.

    x = np.array([10, 20, 30, 40, 50])

    x > 25

Produces a boolean array.

Filtering:

    x[x > 25]

Multiple conditions:

    x[(x > 20) & (x < 50)]

OR:

    x[(x < 20) | (x > 40)]

Important:

    & -> AND
    | -> OR

For NumPy element-wise conditions, do not use Python's
and/or.

[ ] Create boolean conditions
[ ] Filter arrays
[ ] Use multiple conditions
[ ] Understand & and |

21. COPY VS VIEW — IMPORTANT
----------------------------

Understand:

    b = a

versus:

    b = a.copy()

Example:

    a = np.array([1, 2, 3])
    b = a.copy()

    b[0] = 100

Now a and b are independent.

This matters because modifying an array unexpectedly can affect other variables
when they reference the same underlying data.

[ ] Understand assignment/reference
[ ] Understand copy()
[ ] Understand basic view behavior

25. SHAPE THINKING — 🔥 MUST
----------------------------

Before performing an operation, always look at the shape.

Example:

    X.shape
    # (100, 5)

This means:
100 samples
5 features

If:

    weights.shape
    # (5, 1)

Then:

    X @ weights

can produce:

    (100, 1)

You should develop the habit:

    Check shape
    -> Think about operation
    -> Perform operation

This habit becomes critical in Deep Learning.
